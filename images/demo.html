Собственный символ (Custom Symbol)

Комплект файлов для использования на сайте и в тексте. Прозрачный фон. Оптимизировано для телефона и компьютера.



1. Символ как текстовый глиф (U+E000)

Скопируйте символ ниже — он вставлен как настоящий символ из шрифта (Private Use Area). Можно вставлять в текст, чаты, документы (если шрифт установлен или подключён через CSS).



Код:  или Unicode U+E000. Нажмите на блок выше, чтобы скопировать в буфер.

/* CSS для сайта */ @font-face { font-family: 'CustomSymbol'; src: url('CustomSymbol.woff') format('woff'), url('CustomSymbol.ttf') format('truetype'); } .my-icon::before { content: "\E000"; font-family: 'CustomSymbol'; font-size: 1.5em; }

3. Файлы шрифта

  • CustomSymbol.ttf — TrueType (для установки в систему)
  • CustomSymbol.woff — для веб (меньше размер)

Глиф U+E000 — спираль (векторный контур). Можно заменить на любой другой символ из набора, пересобрав шрифт.

4. Как использовать на сайте

<!-- Как иконка-картинка --> <img src="spiral.svg" alt="Symbol" width="48" height="48"> <!-- Как текстовый символ --> <span style="font-family: CustomSymbol;">&#xE000;</span> <!-- CSS background --> .icon { background: url(spiral.svg) center / contain no-repeat; width: 32px; height: 32px; }
